# NJEJE'S FAMILY — public static site

This folder contains a static-only version for GitHub Pages. It does not contain the registration form, API, backend, privacy-notice draft, registration database, or the graduation photo.

To preview locally, open `index.html` in a browser or serve this folder with any static file server. GitHub Pages is configured to use GitHub Actions; the workflow in `.github/workflows/pages.yml` publishes the repository root whenever changes are pushed to `main`.

This version uses Google Fonts from Google's public font CDN. It does not collect or transmit registration data.
